# SwitchBot HACS Integration

This is a HACS-compatible custom component for Home Assistant that restores the SwitchBot integration from Home Assistant version 2026.02.03.

## Why this exists
The built-in SwitchBot integration was broken in Home Assistant version 2026.03. This repository was created to provide a working version of the integration based on the stable 2026.02.03 release, allowing users to continue using their SwitchBot devices until the upstream issue is resolved.

## Support
**Please note: There is NO SUPPORT provided for this custom component.**
This is simply a direct extraction of the Home Assistant 2026.02.03 SwitchBot integration packaged for HACS. It is provided "as is" without warranty of any kind. If you encounter issues, please check the official Home Assistant repository or community forums.
